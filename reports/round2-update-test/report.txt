CVE-2021-0467: plausivel mas nao confirmado / sem evidencia suficiente em S805Y.
- bug: BootROM BL1 WR_LARGE_MEM 0x11, check so em dldata.addr/size, wIndex sem check + ponteiro incrementado por wValue esperado. RCE pre-assinatura, auth bypass.
- confirmado: S905D3 SM1 VIM3L + Chromecast S905D3G, depois s905d2. So G12/SM1 pelo autor.
- forks dizem GXL GXBB s905/s905x/s905w funcionam trocando SRAM addr, mas sem audit, credibilidade media.
- GXL tem mesmo protocolo 1b8e:c003 mas codebase BL1 diferente, SRAM layout diferente, precisa endereco S805Y que nao existe publicado.
- pre-requisitos extras: entrada fisica em USB boot (stick sem botao, precisa short/HDMI dongle boot@USB; warm reboot retém ordem, so cold reset limpa - docs.u-boot.org), password USB em OTP se ligado trava tudo, Chromecast mitigou assim. Aquaman L1/Netflix => alta chance secureboot+password.
- AMLSECU BL33 irrelevante para CVE (CVE e pre-BL2).
- nao tentar CVE so por VID/PID. Primeiro precisa 1b8e:c003 + socid.py + dump BL1 + endereco.
